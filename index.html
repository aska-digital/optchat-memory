Every message stays within reach.

Memory that grows without losing its past.

OptChat stores every Hermes Agent message in a log and organizes older messages into a summary tree. Hermes reads a compact view of the full history and can open any branch to see the original words.

01 / MECHANISM

Keep the full record at the right level of detail.

Recent messages stay detailed. Older messages become short summaries that still link back to the original text.

LOG

Store every turn

User messages, replies, tool calls, tool results, and agent reports go into daily JSONL files, with one record per line. Existing records never change.

TREE

Build summaries upward

Adjacent records merge into parent summaries in a binary tree. A smaller language model creates them in the background while the original log stays intact.

VIEW

Open any level

Hermes receives a compact view of the full history. optchat_zoom opens a summary until it reaches the original message.

02 / PROPERTIES

Built for conversations that outgrow the model’s context window.

The saved history grows with the conversation. The text shown to the model stays within a set character limit.

∞

The log has no fixed length limit. The original text remains available for search and zoom.

01

Original text preserved

The log keeps every original message. Summaries can be rebuilt without changing past messages.

02

Fixed context size

The view keeps recent messages detailed and groups older messages into broader summaries.

03

View saved between runs

The current layout is saved to disk and loaded at startup. This keeps the start of the prompt stable, which lets Hermes reuse its cached work.

04

Handles common failures

Memory reads and background summaries can run together safely. OptChat recovers from partial writes, splits long messages into pages, and limits retry attempts.

03 / INSTALL

Install it from the Hermes catalog.

OptChat is a public Hermes Agent memory provider. Install the plugin, then select it during memory setup.

TERMINAL
$ hermes plugins install optchat
$ hermes memory setup

# choose optchat as the memory provider
